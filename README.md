# CG Combat Framework

> A comprehensive combat framework that supports a multitude of features for any kind of games you have combat in.

## Notes

This is a part of RGS (Re-usable Game Systems) that I have created to help potentially speed up game development.

Within the `Runtime/Samples` folder, there is a prefab that contains an example scene and implementions of this Combat Framework. It may help you to explore the demo scene/scripts to help better understand on the power and extensibility of this framework.

## Features

This Combat Framework supports many different things like:
 - Status Effects (buffs/debuffs, DoTs, HoTs, etc)
 - Resources (health, mana, energy, etc)
 - Stats and StatModifiers
 - Custom Tick System
 - Abilities
 - Weapons
 - `Whatever else I decide to put here!`
